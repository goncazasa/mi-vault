# Vault

Base de conocimiento personal (Obsidian) compartida con Claude, Codex y otras IAs.
Las instrucciones para la IA están en `CLAUDE.md` (y `AGENTS.md`, que es un enlace al mismo archivo).

## Uso en un equipo nuevo
```bash
git clone git@github.com:TU_USUARIO/mi-vault.git ~/vault
```
Luego, en Obsidian: "Open folder as vault" → `~/vault`, e instala el plugin **Obsidian Git**.
